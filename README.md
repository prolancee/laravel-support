## About PROLANCEE Support

**PROLANCEE Support** is a core utility package within the **PROLANCEE Developer Ecosystem**, designed to provide shared infrastructure, helpers, installers, encryption tooling, and foundational services used across PROLANCEE Laravel packages.

It acts as the backbone layer for configuration publishing, file scaffolding, encryption management, and environment setup.

---

## Why PROLANCEE Support?

This package centralizes common responsibilities such as:

- Shared installer commands  
- Configuration publishing & management  
- Database & Redis encryption helpers  
- File scaffolding and environment bootstrapping  
- Consistent force / overwrite handling  
- Cross-package compatibility utilities
